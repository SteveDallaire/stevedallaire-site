# stevedallaire-site

Site web de Steve Dallaire · Formation IA en entreprise (Estrie).

## Structure

- `index.html` : la page d'accueil (une seule page avec ancres)
- `css/style.css` : les styles (couleurs en variables, thème clair et sombre)
- `js/main.js` : calculateur de subvention et formulaire
- `img/` : photos de Steve, optimisées pour le web

## Mise en ligne

GitHub Pages : Settings → Pages → Deploy from a branch → `main` / `(root)`.
